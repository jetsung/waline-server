## 3. 评论提交流程

```
POST /api/comment
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│                      参数校验                                │
│  - url: 必填                                                │
│  - comment: 必填                                            │
│  - nick/mail: 未登录时必填                                   │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│                    登录状态检查                              │
│                                                              │
│  LOGIN=force 且未登录?                                       │
│  └─ 是 → 401 Unauthorized                                   │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│                    验证码检查                                │
│                                                              │
│  配置了 TURNSTILE_SECRET 或 RECAPTCHA_V3_SECRET?            │
│  └─ 是 → 验证 → 失败 → 403                                  │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│                    管理员检查                                │
│                                                              │
│  是管理员?                                                   │
│  └─ 是 → status = 'approved' → 跳过安全检查                  │
└─────────────────────────────────────────────────────────────┘
    │ 否
    ▼
┌─────────────────────────────────────────────────────────────┐
│                    IP 黑名单检查                             │
│                                                              │
│  IP 在 disallowIPList 中?                                    │
│  └─ 是 → 403 Forbidden                                      │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│                    重复内容检测                              │
│                                                              │
│  相同 url + mail + nick + link + comment 已存在?             │
│  └─ 是 → 拒绝: "Duplicate Content"                          │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│                    IP 频率限制                               │
│                                                              │
│  IPQPS 秒内已提交过评论?                                      │
│  └─ 是 → 拒绝: "Comment too fast!"                          │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│                    初始状态设置                              │
│                                                              │
│  COMMENT_AUDIT=true?                                         │
│  └─ 是 → status = 'waiting'                                 │
│  └─ 否 → status = 'approved'                                │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│                    Akismet 检测                              │
│                                                              │
│  status = 'approved' 且配置了 AKISMET_KEY?                   │
│  └─ 是 → 检测 → 垃圾 → status = 'spam'                      │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│                    违禁词过滤                                │
│                                                              │
│  配置了 FORBIDDEN_WORDS 且 status != 'spam'?                 │
│  └─ 是 → 匹配 → 包含 → status = 'spam'                      │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│                    preSave 钩子                              │
│                                                              │
│  执行插件钩子                                                 │
│  └─ 返回错误 → 拒绝                                          │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│                    保存到数据库                              │
│                                                              │
│  modelInstance.add(data)                                     │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│                    Webhook 通知                              │
│                                                              │
│  配置了 WEBHOOK?                                             │
│  └─ 是 → POST { type: 'new_comment', data: {...} }          │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│                    发送通知                                  │
│                                                              │
│  status != 'spam'?                                           │
│  └─ 是 → notify.run(comment, parentComment)                 │
│         ├─ 博主通知 (Server酱/企业微信/QQ/Telegram/...)      │
│         └─ 回复通知 (邮件)                                   │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│                    postSave 钩子                             │
│                                                              │
│  执行插件钩子                                                 │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
返回评论数据
```

## 4. 用户注册流程

```
POST /api/user
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│                    验证码检查                                │
│                                                              │
│  配置了 TURNSTILE_SECRET 或 RECAPTCHA_V3_SECRET?            │
│  └─ 是 → 验证 → 失败 → 403                                  │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│                    检查邮箱是否已注册                        │
│                                                              │
│  邮箱已存在且类型为 administrator/guest?                     │
│  └─ 是 → 拒绝: "USER_EXIST"                                 │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│                    确定用户类型                              │
│                                                              │
│  是第一个用户?                                               │
│  └─ 是 → type = 'administrator'                             │
│                                                              │
│  配置了邮件服务?                                              │
│  └─ 是 → type = 'verify:token:expire'                       │
│  └─ 否 → type = 'guest'                                     │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│                    密码哈希                                  │
│                                                              │
│  password = hashPassword(password)                          │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│                    保存用户                                  │
│                                                              │
│  邮箱已存在? (verify 状态)                                    │
│  └─ 是 → update(data, { email })                            │
│  └─ 否 → add(data)                                          │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│                    发送验证邮件                              │
│                                                              │
│  type 以 'verify:' 开头?                                     │
│  └─ 是 → 发送验证邮件                                        │
│         → 返回 { verify: true }                             │
│  └─ 否 → 返回成功                                           │
└─────────────────────────────────────────────────────────────┘
```

## 5. 用户登录流程

```
POST /api/token
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│                    验证码检查                                │
│                                                              │
│  配置了 TURNSTILE_SECRET 或 RECAPTCHA_V3_SECRET?            │
│  └─ 是 → 验证 → 失败 → 403                                  │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│                    查找用户                                  │
│                                                              │
│  user = await model.select({ email })                        │
│                                                              │
│  用户不存在 / type='verify:xxx' / type='banned'?             │
│  └─ 是 → 拒绝                                               │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│                    密码验证                                  │
│                                                              │
│  checkPassword(password, user.password)                      │
│  └─ 失败 → 拒绝                                             │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│                    2FA 验证                                  │
│                                                              │
│  用户启用了 2FA?                                             │
│  └─ 是 → 验证 code 参数                                      │
│         → 失败 → 拒绝                                       │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│                    生成 Token                                │
│                                                              │
│  token = jwt.sign(user.objectId, jwtKey)                    │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
返回用户信息 + Token
```

## 6. OAuth 登录流程

```
GET /api/oauth?type=github&redirect=/ui/profile
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│                    构建授权 URL                              │
│                                                              │
│  redirect_back = /api/oauth/callback?type=github            │
│  state = base64({redirect: /ui/profile}):jwt_token          │
│  → 重定向到 OAuth 提供商                                     │
└─────────────────────────────────────────────────────────────┘
    │ 用户授权后回调
    ▼
GET /api/oauth/callback?type=github&code=xxx&state=xxx
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│                    获取用户信息                              │
│                                                              │
│  GET {OAUTH_URL}/{type}?code=xxx                            │
│  → { id, name, email, avatar, url }                         │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│                    查找已绑定账户                            │
│                                                              │
│  user = await model.select({ [type]: user.id })             │
│                                                              │
│  已绑定?                                                      │
│  └─ 是 → 生成 Token → 重定向到 redirect?token=xxx           │
└─────────────────────────────────────────────────────────────┘
    │ 未绑定
    ▼
┌─────────────────────────────────────────────────────────────┐
│                    检查当前登录状态                          │
│                                                              │
│  已登录 (state 中有 jwt_token)?                              │
│  └─ 是 → 绑定 OAuth 到当前账户                               │
│         → 重定向到 /ui/profile                              │
└─────────────────────────────────────────────────────────────┘
    │ 未登录
    ▼
┌─────────────────────────────────────────────────────────────┐
│                    创建新账户                                │
│                                                              │
│  是第一个用户?                                               │
│  └─ 是 → type = 'administrator'                             │
│  └─ 否 → type = 'guest'                                     │
│                                                              │
│  创建用户:                                                    │
│  {                                                           │
│    display_name: user.name,                                  │
│    email: user.email,                                        │
│    avatar: user.avatar,                                      │
│    [type]: user.id,                                          │
│    ...                                                       │
│  }                                                           │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│                    生成 Token 并返回                         │
│                                                              │
│  token = jwt.sign(newUser.id, jwt_secret)                   │
│  → 重定向到 redirect?token=xxx                               │
└─────────────────────────────────────────────────────────────┘
```

## 7. 通知发送流程

```
notify.run(comment, parentComment)
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│                    确定通知对象                              │
│                                                              │
│  isAuthorComment = comment.mail === AUTHOR_EMAIL            │
│  isReplyAuthor = parent?.mail === AUTHOR_EMAIL              │
│  isCommentSelf = parent?.mail === comment.mail              │
└─────────────────────────────────────────────────────────────┘
    │
    ├─────────────────────────────────────────────┐
    │                                             │
    ▼                                             ▼
┌───────────────────────────────┐   ┌───────────────────────────────┐
│        博主通知                │   │        回复通知                │
│                               │   │                               │
│  条件:                         │   │  条件:                         │
│  - !DISABLE_AUTHOR_NOTIFY     │   │  - parent 存在                 │
│  - !isAuthorComment           │   │  - parent.mail 有效            │
│  - !disableAuthorNotify       │   │  - !isCommentSelf              │
│                               │   │  - !isReplyAuthor              │
│  优先级:                       │   │  - status != 'waiting'         │
│  1. Server酱                  │   │                               │
│  2. 企业微信                   │   │  方式:                         │
│  3. QQ                        │   │  - 邮件                        │

│  6. Discord                   │   │                               │

└───────────────────────────────┘   └───────────────────────────────┘
